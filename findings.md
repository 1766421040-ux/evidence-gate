# EvidenceGate optimization record

This record continues the user-authorized local optimization after the published V2 quality failure. It records measured evidence separately from plans. No cloud GPU or paid inference is used.

1. **The main V2 failure is the action decision.** Existing answer emissions on answerable cases copied values and citations correctly, but many answerable cases emitted search/abstain. A stratified 64-row train/dev diagnostic also found this failure on training examples. Correct-prefix copying is conditional evidence, not proof that every refused case would answer correctly.
2. **Low average loss is insufficient evidence.** Manual shifted completion CE matches the installed Transformers loss within 7.45e-9. Prompt tokens are masked. Action tokens account for about 99.7% of residual NLL in the diagnostic; this is not a gradient-norm measurement. Action weighting was deferred.
3. **Capacity alone did not pass.** Keeping V2 data, seed, schedule and 600 updates fixed, broadening rank-8 LoRA from q/v to all seven linear projections moved full-dev answer success from 13/48 to 23/48, but over-answering from 10/120 to 19/120. Total strict success changed from 123/168 to 124/168; complete-group success stayed 0/12. This is a failed quality intervention, preserved in `experiments/v3/capacity-probe/`.
4. **Data coverage required two revisions before model testing.** V2 text cues identified some answer classes without complete evidence checking. The unused V3 freeze crossed those cues and both budgets. A further train/dev-only audit found topic and multiple-official-source gaps. V3.1 adds current irrelevant-topic documents, two-source consensus with exact dual citations, and uniform wrong-topic negatives. Both earlier freezes and all negative evidence remain preserved. New data is a hypothesis about better learning, not a model result.
5. **Average-score selection was inadequate.** V2 selected a checkpoint with weaker answer recall. V3.1 requires all original six gates plus emitted-answer contract failure at most 5% on one complete dev evaluation before ranking. Undefined risk and very few answers cannot pass. Final test is inaccessible through the guarded runner until selection and artifact identity are rechecked.
6. **Training and development selection completed.** The registered V3.1 standard-SFT run completed 2,400 optimizer updates on 1,920 train rows (five complete shuffled epochs) in 5,568.608 seconds. It trained 4,399,104 LoRA parameters, used at most 499 input-plus-completion tokens and truncated no samples. Four complete 576-row dev evaluations selected step 2400 under all seven frozen gates: 576/576 strict, 288/288 answerable and 24/24 complete groups. Independent raw-output scoring reproduced the selection. Step 1800 had five future-evidence errors and one wrong citation set; step 2400 corrected all six without a new dev failure. These are selection results, not final test estimates. The subsequent single frozen confirmation is reported below.

`unsupported_answer_rate` includes an answer in an unanswerable state, a wrong value, or a wrong/incomplete citation set. It is an evidence-contract failure rate among emitted answers, not a pure factual-hallucination rate. Passing these synthetic gates does not establish production or unrestricted language robustness.

7. **The declared final protocol passed; a local date weakness remains.** Independently re-scored raw generations give 1437/1440 strict, 720/720 answerable, 58/60 complete groups, 3/720 over-answering, 3/723 emitted-answer contract failures and macro-F1 0.99822677. All seven predeclared gates pass. The three errors all use next-day evidence across March 31 to April 1; this post-hoc cross-month future slice is only 1/4 correct across two groups, versus 116/116 within-month. This weakness is disclosed, not repaired or used to select another checkpoint.
8. **The same-test reference confirms the answerability improvement.** The fixed historical V2 adapter on this V3.1 test scores 751/1440 strict, 184/720 answerable, 152/720 over-answering and 155/339 emitted-answer contract failures. Base has no format-valid outputs; the complete contract rule is perfect. These controls do not isolate the causal effect of individual training changes. The earlier V2 test result remains unchanged and is not substituted for the same-test comparison.
