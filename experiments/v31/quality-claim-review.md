# V3.1“质量达标”措辞审查

审查时间：2026-10-27。本次只读协议、注册表、评分/选模代码及 dev 数据；未读取 test 内容或任何新模型预测，未运行模型。以下是协议审查，不是训练结果。未修改冻结文件或验收阈值。

## 结论与可用措辞

七门槛适合判定**预先声明的有限合成任务是否通过联合验收**。当前训练尚未完成，不能写“已达标”。只有完整 dev 选择、选中权重核验、一次冻结 test 确认及原始输出复算都通过后，才可写：

> 该 LoRA 在 V3.1 的新产品实体合成留出集上，通过了预先冻结的七项联合验收；报告同时披露 24 个情境单元的结果和成组置信区间。

不能据此写“通用 Agent 已可靠”“真实企业知识库达到生产质量”“所有情境均达 85%”“95% 置信保证风险低于 5%”，或把软件 CI 通过当成模型通过。

## 必须修复的软件缺陷

**本次未发现七门槛与 24 单元评分存在必须修改的实现缺陷。** `selection_v3.py` 对计数比率使用精确分数；七项同时通过后才排序；未定义风险指标和回答数不足不会通过。`score` 对动作、值、引用共同计分；`summarize` 的整组正确率覆盖实际全部 24 行，两个新情境没有被漏掉。独立 topic/agreement 配对诊断不改写主摘要或门槛。当前训练源码、配置文件 SHA 与注册记录一致。

这个结论仅覆盖本次检查范围，不代替训练完成后的原始输出、checkpoint、选择记录和一次确认记录核验。

## 必须声明的实验局限

| 范围 | 可以支持与不能支持的结论 |
| --- | --- |
| 合成分布 | 三种固定问法主题、三种套餐、离散天数、固定三篇文档和显式 authority/date 字段；产品实体隔离检验同一语法下的新实体组合，不能代表真实文档抽取、开放域事实核验或措辞迁移。每组 12/24 行可答；search、abstain 各 5/24，clarify 为 2/24。这是设计分布，不是线上发生率。 |
| 已知捷径 | 新反例使两条已知不充分规则不过联合门槛；不等于排除所有捷径，也不证明模型确实采用了正确证据推理。社区文本及注入尾句高度固定，不能据此宣称广泛的提示注入鲁棒性。公开合同规则在这个语法内可完美解题，因此 SFT 的必要性并未被证明。 |
| 24 单元与聚合门槛 | 联合达标不保证每个单元都达到总体阈值。整组全部正确 ≥50% 至少约束每个单元在一半组上正确，但仍允许某个单元仅 50% 正确。必须保留完整 `by_variant`、混淆矩阵和新增配对结果；不能仅展示总分。 |
| 单种子和选择 | 数据 seed 为 20261030，训练 seed 为 42；四个 checkpoint 来自同一训练轨迹，不是四次独立复现实验。dev 用于挑选 checkpoint，其成绩是选择证据，不能作为最终无偏估计。60 个 test 组只进行选中候选的一次确认。 |
| 置信区间 | 当前总体成功率使用按完整产品组重采样的 percentile bootstrap：1,000 次、seed=17。24 行组内相关，不能按 1,440 独立样本计算区间。现有区间仅描述该合成分布下产品组的重采样变化，不包含训练种子、模型规模、数据设计和线上分布的不确定性；低变化或退化区间不是稳定性证明。门槛检查点估计，未使用置信区间下界作门槛。 |
| 双引用严格评分 | consensus 要求两篇适用官方证据的 ID 集合完全一致，排列无关。正确值但只引一篇仍失败；`unsupported_answer_rate` 也将其计入。因此它是“已答中违反动作/值/引用合同的比例”，不能直接称作事实幻觉率。过度回答率以不可答行为分母；两者分母不同。 |
| 归因与 Agent 范围 | V3.1 同时改变数据覆盖、训练预算和适配模块，相对 V2 的改善只能归于这组改动，不能单独归于反事实数据。search 的预算决策和固定可恢复协议不是开放检索或最优搜索策略；主验收不支持多轮工具执行及生产安全结论。 |

### 聚合门槛边界的 CPU 反例

仅在 dev 标签上构造一个**非模型、非实测结果**：令其他行全部正确，只让 24 组中 12 组的 `future_b1` 错误输出 abstain。用现有 `score/summarize` 和七门槛的精确分数重算，得到：

- `future_b1`：12/24，即 **50%**；整组正确：12/24，即 **50%**。
- 总体成功：564/576，即 **97.92%**；可答成功、格式合法均为 100%。
- macro F1 为 0.97494，过度回答与已答合同错误比例均为 0，已回答 288 行。
- 七项同时通过。

这不是要求新增门槛，而是说明既有门槛的准确语义：允许联合达标措辞，同时必须披露可能集中的情境缺陷。
