# float32 失败尝试

首次 float32 / MPS 尝试在第 67 个优化器更新步发生内存不足，计划的 200 步未完成。本目录保留实际完成的 66 步训练日志和原始配置清单，避免只展示成功尝试。

- `metrics.json`：第 1–66 步的实际记录，逐字节复制自该次运行。
- `run_manifest.json`：当时的模型、数据和配置绑定。
- `failure.json`：失败状态与记录边界；原终端堆栈未包含在本次发布中。

该次使用 float32、micro batch 2、梯度累积 2、最大长度 768，未启用梯度检查点。后续重新从基础模型开始，以 bfloat16、固定长度 padding、micro batch 1、梯度累积 4、最大长度 512、梯度检查点完成两个 200 步运行。多个设置同时改变，因此这里不单独归因于某一个内存优化。

失败尝试的数据／配置哈希与后续正式运行不同，其部分 loss 不用作配对质量比较。未发布失败权重或 checkpoint，未将其算作完成训练。
